# React Chat App

A single-page chat application built for a React assignment. Users can write messages, send them to the chat feed, react to individual messages with likes, and add emojis with a simple built-in picker.

## Features

- Send text messages from the input at the bottom of the page.
- Display sent messages in the chat feed.
- Randomly assign each new message one of five usernames: Alan, Bob, Carol, Dean, or Elin.
- Like each message independently.
- Add emojis at the cursor position using the emoji picker.
- Close the emoji picker after choosing an emoji or clicking outside it.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- React with functional components and `useState`
- JavaScript (ES6+)
- CSS
- Vite

## Installation

1. Clone or download this project.
2. Open a terminal in the project folder.
3. Install the dependencies:

```bash
npm install
```

## Run the Application

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually `http://localhost:5173/`.

## Other Commands

Create a production build:

```bash
npm run build
```

Check the project for linting issues:

```bash
npm run lint
```
